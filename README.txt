Allez! French A1 - upload these files to a GitHub repo, then turn on GitHub Pages.
1. github.com > New repository (public), e.g. "allez-french".
2. "uploading an existing file" > drag ALL files from this folder (not the folder itself) > Commit.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
4. After ~1 minute open https://YOURNAME.github.io/allez-french/ on your phone.
5. iPhone Safari: Share > Add to Home Screen. Android Chrome: menu > Install app.
